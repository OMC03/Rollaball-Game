# Roll A Ball Game
### Description
This is a repository of my a Roll A Ball Game where you need to collect cubes which dodging an AI enemy. 

This project uses Unity's Nav Mesh library to create responsive AI's that react to the enviornment around them.

Static and Dynamic Obstacles are used to create permanent and ever changing surroundings allowing for the AI to change its path based on its current position in the world
